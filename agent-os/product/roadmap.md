# Product Roadmap

## Priority: Admin Dashboard, Matching, and Email

1. [ ] Admin Dashboard Overview — Create a dashboard landing page showing key metrics: active mentorships count, pending matches, unmatched applicants, available mentors, and recent activity `S`

2. [ ] Admin Match Review UI — Improve pending matches interface with match scores displayed, mentor/applicant details side-by-side, and one-click approve/reject actions `M`

3. [ ] Matching Algorithm Transparency — Display scoring breakdown (country, distance, preferences) in admin match view so admins understand why matches were suggested `S`

4. [ ] Email Delivery Status Tracking — Add delivery status tracking for monthly check-in emails with admin visibility into which emails succeeded/failed `M`

5. [ ] Manual Match Creation UI — Build admin interface to manually create matches by searching/selecting mentor and applicant, bypassing auto-match when needed `S`

6. [ ] Mentorship Timeline View — Create admin view showing mentorship progress: which monthly emails sent, days until next email, overall health of each mentorship `M`

7. [ ] Email Preview and Testing — Allow admins to preview monthly email content and send test emails before they go out to real users `S`

8. [ ] Unmatched Applicant Queue — Build prioritized queue showing unmatched applicants sorted by wait time, with quick actions to find and assign mentors `S`

9. [ ] Mentor Availability Management — Add UI for admins to mark mentors as unavailable/on-break without losing their profile, and re-activate when ready `S`

10. [ ] Match Quality Feedback — Capture simple feedback at mentorship end (completed successfully, ended early, no contact) to improve future matching `M`

> Notes
> - Items ordered by admin workflow: overview first, then match management, then email visibility
> - All items support the goal of reopening the programme with better operational tooling
> - Effort: XS (1 day), S (2-3 days), M (1 week), L (2 weeks), XL (3+ weeks)
